# Security Engineering Career Lab

A hands-on learning repository for developing the practical programming, cloud security, DevSecOps, and application-security skills expected in senior security engineering and architecture roles.

- [Python Security Lab](python-security-lab/README.md)

## Run the lab

```bash
cd python-security-lab
python3 run_demo.py
python3 -m unittest discover -v
```

The first phase uses only Python's standard library. It requires no cloud account, paid subscription, or external package.
